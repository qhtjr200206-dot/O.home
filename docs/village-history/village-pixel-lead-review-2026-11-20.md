# 마을 게임·도트 독립 검토 기록 — 미완성, 배포 금지

## 범위와 역할

- 팀장: hobby 프로필, openai-codex `gpt-6.1-terra`. 운영 데이터 쓰기와 규칙 적용 금지.
- 독립 설계·보안 검토: 같은 모델의 별도 세션 `20261120_030407_ac3dff` (위임 `deleg_03976eff`, task 0). 실제 DB 공격이나 운영 규칙 확인은 하지 않은 정적 검토다. 검토자는 원본 사용자 지시 파일을 찾지 못했으므로 팀장이 직접 읽은 사용자 확정 정책을 기준으로 후속 설계해야 한다.
- 독립 도트 비주얼 검토: 같은 모델의 별도 위임 세션 `deleg_03976eff`, task 1. 비교표 이미지와 소스, 테스트 검토. 이종 모델 검토가 아니다.

## 현재 차단 사유

- 게임은 정책 함수와 맵 생성기만 있는 상태다. 실제 인증 API, 방 저장소, 서버 검증, 공유 시도 제한, 세션 발급/폐기, UI 및 동기화는 구현·검증되지 않았다. 메모리 테스트 더블로 DB 원자성이나 직접 접근 차단을 입증할 수 없다.
- 일반 가입자는 동시에 활성/삭제 처리 중 방 하나, 삭제 완료 후 재생성 가능; 관리자는 무제한이라는 최신 확정 정책을 실제 DB 트랜잭션과 삭제 정리에 구현해야 한다. 역할 강등 및 생성·삭제 경합도 검증해야 한다.
- 독립 보안 검토에서 기존 콘텐츠 작성자/권한 필드를 서버 권한 근거로 그대로 신뢰하기 전 Firebase 규칙과 Supabase INSERT 정책을 격리 환경에서 검증해야 한다고 지적했다. 실제 배포 규칙이나 실제 공격 성공 여부는 확인되지 않았다.
- 도트 SVG는 128×160 좌표계이나 기존 저해상도 디자인 확대에 크게 의존하고, 24개 래스터가 다르다는 것만으로 100×100 원본 수준 디테일이나 각각 시각적으로 구분되는 20종을 입증하지 못한다. 독립 검토는 특히 표정 1/13과 몸 13/14가 미세하게 다르다고 지적했다. 검정·흰색 및 피부와 유사한 눈 색의 대비, 레거시 외형, 모바일과 실제 편집기 조작도 미검증이다.
- 운영 보안 규칙은 적용하거나 변경하지 않는다. 실제 규칙이 안전하게 적용되었는지 확인할 수 없으면 게임을 노출하거나 배포하지 않는다.

## 후속 검증

원본 해상도에 맞춰 도트를 재설계하고 독립 비교표·격리 브라우저·모바일에서 확인한다. 서버와 백엔드별 접근 차단을 실제로 구현하고 격리된 Firebase 에뮬레이터 및 Supabase 테스트 DB에서 위조·격리·동시 생성·삭제·재생성·세션 폐기를 공격 검증한다. 기존 캐릭터 소유/권한의 신뢰 경계와 실제 운영 규칙을 확인하고 필요한 운영 적용은 소유자에게 요청한다. 수정 후 독립 QA·보안 재검증 및 실제 접근 흐름 검증 전에는 완료 또는 배포를 주장하지 않는다.
